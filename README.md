## ✨ Sobre o Projeto
Este é o meu portfólio **profissional e responsivo**, criado para apresentar meus projetos, habilidades e trajetória como desenvolvedora web.  
O design foi pensado para ser **moderno, acessível e mobile-first**, garantindo uma ótima experiência tanto em desktops quanto em dispositivos móveis.  

💡 Além da apresentação visual, o projeto conta com **formulário de contato funcional** e **chat flutuante**, permitindo interações rápidas e simples.

---

## 🎨 Layout & Design
- 🎯 **Tema de cores:** roxo (`#5a3d73`) e tons complementares  
- 🖼️ **Estilo:** clean, moderno e minimalista  
- 📌 **Seções do site:**
  - 👩‍💻 **Banner Dev** → apresentação com animações e destaques  
  - 🙋‍♀️ **Sobre Mim** → trajetória profissional  
  - ⚡ **Skills** → tecnologias com ícones e animação hover  
  - 📂 **Projetos** → cards responsivos com imagens e descrição  
  - 📬 **Contato** → formulário funcional + chat  
  - 🔗 **Footer** → assinatura e créditos  

---

## 🛠️ Tecnologias Utilizadas
- **HTML5** → estrutura semântica  
- **CSS3** → layout responsivo + animações  
- **JavaScript (ES6)** → efeitos e interatividade  
- **Google Fonts** → tipografias modernas (Roboto & Caveat)  
- **Font Awesome** → ícones de contato e redes sociais  
- **Mobile First** → ajustes em `@media` para diferentes breakpoints (1600px, 1024px, 768px, 480px)  
- **Formspree** → integração do formulário de contato sem backend  

---

## 📱 Responsividade
✔ Banner e imagens animadas ocultadas em telas pequenas para melhor performance  
✔ Textos, títulos e botões adaptados para **smartphones e tablets**  
✔ Layout ajustado para não gerar **scroll lateral** em nenhuma seção

## 📬 Formulário de Contato
O formulário foi integrado via **[Formspree](https://formspree.io/)** para envio direto de mensagens ao e-mail configurado.  

### Estrutura:
```html
<form
  id="contact-form"
  action="https://formspree.io/f/xanwrjew"
  method="POST"
>
  <div class="input-group">
    <label for="name">Nome<i class="fa-solid fa-asterisk"></i></label>
    <input type="text" id="name" name="name" required />
  </div>

  <div class="input-group">
    <label for="email">Email<i class="fa-solid fa-asterisk"></i></label>
    <input type="email" id="email" name="email" required />
  </div>

  <div class="input-group">
    <label for="message">Mensagem<i class="fa-solid fa-asterisk"></i></label>
    <textarea id="message" name="message" required></textarea>
  </div>

  <button type="submit" class="contact-btn">Enviar</button>
</form>
````
